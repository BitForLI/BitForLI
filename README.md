# Reese Lee

I am a Master of Computer Science student at the University of Sydney. I build backend, data, and full-stack systems, usually around problems where correctness matters more than a polished happy-path demo.

Recent work includes:

- [StreamPulse](https://github.com/BitForLI/StreamPulse) - an event-time CDN analytics pipeline with Kafka, Flink, ClickHouse, and Grafana.
- [Fulfilment Optimizer](https://github.com/BitForLI/timefold-quickstarts/tree/codex/fulfilment-optimizer/use-cases/fulfilment-optimizer) - a Java constraint-optimisation service with a deterministic greedy baseline.
- [Pagefold](https://github.com/BitForLI/FileMoney) - a local-first Markdown desktop app built with Electron, React, and TypeScript.
- [CloudNativeLLMOps](https://github.com/BitForLI/CloudNativeLLMOps) - an asynchronous FastAPI and AWS workload with durable jobs, evaluation, observability, and deployment gates.

I work mainly with Java, Python, TypeScript, C#, Go, SQL, PostgreSQL, AWS, Docker, and Terraform. I care about reproducible tests, useful failure messages, and documentation that explains the decisions a maintainer actually needs.
