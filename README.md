# Reese Lee

I am finishing a Master of Computer Science at the University of Sydney. I enjoy backend work, but I usually start with a user problem rather than a framework. I tend to stay with a problem until I understand why the system works, not only until the code runs.

## Four projects I would show first

- **[PodRepeat](https://github.com/BitForLI/language-learning-podcast-app)** is the one I use to explain how I think about products. It turns a podcast transcript into something a learner can tap, replay, translate, and return to later. I built it because most podcast apps are designed for discovery, while I wanted to study a small number of episodes properly.
- **[Grocery Ordering Workflow Demo](https://github.com/BitForLI/grocery-ordering-demo)** is an independent reconstruction of workflows I encountered during an internship. It follows an order beyond checkout, including store preparation, actual-weight pricing, partial refunds, and customer notifications. It contains no employer source code.
- **[Pagefold](https://github.com/BitForLI/pagefold-markdown-notes)** is a Windows Markdown editor that keeps notes as ordinary files. The interesting part was not the editor toolbar; it was deciding what should happen when another program changes a file while the user still has unsaved work.
- **[AI Customer Support Assistant](https://github.com/BitForLI/ai-customer-support-assistant)** explores a boundary I care about in AI software: answering useful questions with evidence while leaving sensitive actions to a person.

I have also used smaller engineering projects to learn about [asynchronous LLM jobs](https://github.com/BitForLI/reliable-llm-job-platform), [stream processing](https://github.com/BitForLI/realtime-cdn-analytics), and [data pipelines](https://github.com/BitForLI/telco-churn-lakehouse). They are experiments, not claims of production experience.
